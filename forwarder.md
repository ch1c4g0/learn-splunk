
<p><h1>Splunk Forwarder</h1></p>

<p>A lightweight agent installed on the monitored endpoint, it's main task is to collect data and forward it to the splunk instance.</p>

<p><h2>The following are key data sources,</h2></p>

> - Web server generating web traffic
> - Windows machine generating event logs, ps, and sysmon.
> - Linux host generating host-centric logs
> - Database generating DB conenction requests, responses, and errors.
